# Инструкция инженера — план, стены и проёмы

Короткая памятка по работе с планом в роли **инженера по сооружениям**.
Интерфейс всегда доступен по кнопке **«?»** в шапке, а также по кнопке
«Открыть инструкцию» на левой панели и в сводке справа.

## Что доступно инженеру

- План этажа (актуальный чертёж).
- Перегородки: добавить, выделить, перетащить за линию или за жёлтые маркеры концов, изменить толщину, удалить.
- Стены модели (сняты с актуального чертежа) доступны для редактирования и удаления: в режиме «Редактор стен» показывается векторная модель, подложка-чертёж при этом скрыта. Переключатели «Стены модели» и «Чертёж» взаимоисключающие.
- Проёмы: дверь, окно, технологический проём — добавить, изменить тип/ширину, удалить.
- Линейка и текстовые пометки.
- Печать листа A4 и сохранение проекта в JSON через меню «Экспорт».

Сеть, оборудование, кабели, кабельный журнал и документация доступны только
администратору. Администратор может включить **«Режим инженера»** в шапке —
интерфейс станет таким же, без ввода пароля.

## Быстрый старт

1. Выберите инструмент на панели сверху или нажмите клавишу:
   - **W** — перегородка;
   - **D** — дверь, **O** — окно, **P** — проём;
   - **V** — выбор, **H** — панорама;
   - **M** — линейка, **T** — текст.
2. **Перегородка:** кликните начало и конец стены. Линия автоматически
   выровняется по горизонтали или вертикали.
3. **Проём:** выберите дверь/окно/проём и кликните по нужной стене.
   В стене появится разрыв с условным обозначением.
4. **Свойства:** нажмите **V**, кликните по стене или проёму. Справа
   откроется инспектор: для стены — толщина, для проёма — тип и ширина.
5. **Удаление:** выделите объект и нажмите **Del**. Удалить можно перегородки,
   проёмы и старые стены; для несущей стены появится подтверждение.
6. **Отмена:** **Ctrl+Z** отменяет действие, **Ctrl+Shift+Z** (или Ctrl+Y) возвращает; кнопки Undo/Redo есть в шапке.
7. **Редактор стен:** показывается векторная модель без растровой подложки, поэтому удаление и перетаскивание сразу видны. «Чертёж» — подложка для сверки (не редактируется), «Стены модели» — векторный слой. Выделите стену (V), перетащите за линию или концы, правьте толщину справа, удаляйте Del.
8. **Навигация:** колесо мыши — масштаб, **H** — панорама, кнопка
   «Вписать» — весь план, **R** — поворот плана на 180° (подписи остаются
   читаемыми).
9. **Сохранение:** изменения синхронизируются автоматически. Если сверху
   появился баннер «Нет связи…» — дождитесь переподключения; при долгом
   обрыве проверьте Wi-Fi и обновите страницу.

## Проёмы

| Инструмент | Что ставит | Ширина по умолчанию |
|---|---|---|
| **D** | Дверь | 0,9 м |
| **O** | Окно | 1,4 м |
| **P** | Технологический проём | 1,1 м |

- Ставятся кликом по стене.
- Ширину и тип можно изменить справа после выделения.
- Два проёма в одном месте поставить нельзя — появится подсказка.
- Удаление: выделить проём и нажать **Del** или кнопку-корзину в инспекторе.
- При удалении стены удаляются и все её проёмы.

## Клавиши

| Клавиша | Действие |
|---|---|
| V | Выбор и свойства |
| H | Панорама |
| W | Перегородка |
| D | Дверь |
| O | Окно |
| P | Проём |
| M | Линейка |
| T | Текстовая пометка |
| R | Поворот плана на 180° |
| Esc | Отменить текущий инструмент |
| Del | Удалить выбранное |
| Ctrl+Z | Отменить действие |
| Ctrl+Shift+Z / Ctrl+Y | Вернуть действие |
| Колесо | Масштаб |

## Если что-то не получается

- **Стена не рисуется** — проверьте, выбран ли инструмент «Перегородка» (W),
  и кликните две точки на плане.
- **Проём не ставится** — кликните точно по линии стены; в одном месте уже
  может быть проём.
- **Объект не выделяется** — нажмите Esc, затем V, и кликните по объекту.
- **Несущую стену нельзя двигать**, но можно удалить — подтвердите действие
  в диалоге.
- **Баннер «Нет связи…»** — подождите несколько секунд: переподключение
  происходит автоматически. Если не проходит дольше минуты — проверьте
  сеть и обновите страницу (F5).
- **План перевёрнут** — нажмите R или кнопку поворота внизу справа, чтобы
  вернуть исходную ориентацию.
