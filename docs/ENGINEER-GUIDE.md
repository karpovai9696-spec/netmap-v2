# Инструкция инженера — планировка в RoomCAD, сеть и документы

Короткая памятка по работе с планировкой и сетью. Интерфейс всегда доступен
по кнопке **«?»** в шапке, а также по кнопке «Открыть инструкцию» на левой
панели и в сводке справа.

## Что где

| Задача | Где |
|---|---|
| Стены, двери, окна, проёмы, комнаты | **RoomCAD** — кнопка «Планировщик» в шапке |
| Подложка плана | **RoomCAD** — кнопка «Подложка» и инспектор справа |
| Печать планировки / PDF | **RoomCAD** — «Экспорт» → «Печать / PDF» |
| Экспорт `.rcad` и `.svg` | **RoomCAD** — меню «Экспорт» |
| Совместная работа над планом | **RoomCAD** — кнопка «Совместно» |
| Сеть, оборудование, кабели | **netmap** (администратор) |
| Кабельный журнал и документация | **netmap** |

Старый редактор стен в netmap **выведен**: вкладки «Редактор стен» и
инструментов стен/проёмов больше нет. В netmap план нужен для привязки сети
и документов.

## Быстрый старт

1. Нажмите **«Планировщик»** в шапке. RoomCAD откроется в новой вкладке,
   ваша учётная запись передаётся автоматически — второй пароль не нужен.
2. В RoomCAD выберите нужную комнату.
3. Редактируйте план: **Стена**, **Дверь**, **Окно**, **Общая зона**, **Подпись**,
   **Комнаты** — кнопки на левой панели.
4. **Подложка:** нажмите «Подложка» и выберите файл плана. Справа настройте
   X/Z, ширину, длину и прозрачность. «Удалить подложку» убирает растровый
   чертёж, оставляя только модель.
5. **Печать:** меню «Экспорт» → «Печать / PDF» (A4 landscape). Там же
   «Чертёж (.svg)» и «Файл RoomCAD (.rcad)».
6. **Сохранение:** в RoomCAD нажмите «Сохранить»; совместная работа — кнопка
   «Совместно». Изменения синхронизируются и сохраняются на сервере.

## Подложка

- Загружается кнопкой **«Подложка»** в тулбаре RoomCAD.
- Справа в инспекторе комнаты задаются:
  - **X / Z** — отступ подложки в метрах;
  - **ширина / длина** — размер в метрах;
  - **прозрачность** — 5–100 %.
- **«Удалить подложку»** убирает серый растровый чертёж; жёлтая модель стен
  остаётся.
- Если подложка не нужна, её можно не загружать вовсе — комната хранит только
  модель.

## Печать и экспорт

В RoomCAD в меню **«Экспорт»**:

| Пункт | Результат |
|---|---|
| **Печать / PDF** | лист A4 landscape, открывается системный диалог печати |
| **Чертёж (.svg)** | векторный измеренный чертёж для другого ПО |
| **Файл RoomCAD (.rcad)** | проект со стенами, проёмами, комнатами и подложкой |

Печать схемы сети и кабельный журнал остаются в netmap: меню «Экспорт».

## Клавиши в netmap

| Клавиша | Действие |
|---|---|
| V | Выбор |
| H | Панорама |
| M | Линейка |
| T | Текстовая пометка |
| R | Поворот плана на 180° |
| Esc | Отменить текущий инструмент |
| Del | Удалить пометку или объект сети |
| Ctrl+Z | Отменить действие |
| Ctrl+Shift+Z / Ctrl+Y | Вернуть действие |
| Колесо | Масштаб |

Клавиши RoomCAD (стены, проёмы, комнаты, подложка) действуют внутри
планировщика; подсказки показывает нижняя строка RoomCAD.

## Сеть и документы

- Сеть, оборудование, IP/VLAN, кабели и кабельный журнал доступны
  администратору.
- Инженер видит документацию в режиме чтения; сеть скрыта.
- Администратор может включить **«Режим инженера»**, чтобы скрыть сеть
  и оставить план и документы.

## Если что-то не получается

- **Не открывается планировщик** — проверьте, что вы в корпоративной сети
  и доступен `http://192.168.1.227:8093/`. Кнопка открывает новую вкладку;
  разрешите всплывающие окна для netmap.
- **В RoomCAD просят пароль** — единый вход не сработал; войдите логином
  и паролем RoomCAD. Для SSO нужна активная сессия netmap.
- **Старые кнопки/английский интерфейс** — обновите вкладку RoomCAD через
  **Ctrl+F5**: могла остаться вкладка от предыдущей версии.
- **3D-прогулка пишет про WebGPU** — нужен свежий Chrome/Edge с WebGPU;
  2D-план при этом работает.
- **Подложка не совпадает с моделью** — поправьте X/Z и размеры справа;
  если подложка не нужна, удалите её.
- **Баннер «Нет связи…»** — подождите переподключения; при долгом обрыве
  проверьте сеть и обновите страницу.
- **План перевёрнут** — нажмите R или кнопку поворота внизу справа.
