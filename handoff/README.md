# Передача точной векторизации плана в Gemini

## Честный ответ

Автоматически получить **редактируемую** модель «пиксель в пиксель» из растра
нельзя. Gemini (4 Argon) это подтвердил: реальный потолок — 85–92 % точности
черновика + ручная доводка. Визуально точная копия уже есть — это сам чертёж
(растровая подложка); она показывается по умолчанию и не является моделью.

## Что приложить к сообщению в Gemini

1. `handoff/plan.png` — исходный чистый чертёж 1152×928.
2. `handoff/plan-drawing.svg` — точная VTracer-трассировка (визуальный эталон).
3. `handoff/walls-hough-142.json` — 142 автоматических отрезка (координаты в метрах).
4. `handoff/walls-skeleton-25.json` — скелетная попытка (для сравнения, неполная).

## Готовый промпт

```text
Ты помогаешь сделать точную редактируемую векторную модель плана этажа
(стены, проёмы, помещения) по приложенному растру 1152×928 и SVG-трассировке.

Координаты:
- полезная область bbox: x=33, y=223, w=993, h=580;
- реальные размеры: 36.81 м (X) × 17.27 м (Y);
- масштаб по осям разный: X ≈ 37.07 мм/px, Y ≈ 29.78 мм/px — учти анизотропию.

Формат модели в приложении (JSON):
{
  "walls": [{"id":"DW-001","x1":0.0,"y1":0.0,"x2":10.0,"y2":0.0,"thickness":0.12,"loadBearing":false}],
  "openings": [{"id":"OP-1","wallId":"DW-001","type":"door|window|opening","offset":1.2,"width":0.9}]
}
Единицы — метры, координаты от левого верхнего угла bbox.

Что нужно:
1. Очисти 142 отрезка: убери размерные линии/выноски/текст, склей двойные
   линии стен в центральные оси, выровняй H/V, притяни узлы.
2. Верни чистый JSON стен (ориентировочно 55–70 стен) с толщиной.
3. Отдельно перечисли проёмы, которые видно на растре (координаты вдоль стены).
4. Дай оценку точности и список мест, где нужна ручная проверка.

Не выдумывай скрытые элементы: если сомневаешься — помечай "needsReview": true.
```

## Как передать

Gemini в этом чате **не видит локальные файлы и изображение**. Варианты:

- открыть чат Gemini и вручную приложить `handoff/plan.png` + текст промпта;
- дать доступ к vision-API (например, Qwen2.5-VL) и передать изображение туда;
- либо оставить растровый чертёж как точный визуальный план, а векторную
  модель использовать только для новых перегородок и проёмов.
